# IN-SITU / 大型齿轮渐开线齿形误差在位测量仪

交互式 WebGL 展陈页。场景单位为毫米，机械运动、采样读数、误差链与界面标注使用同一套配置（`src/config.js`）；Three.js 为本地固定版本，页面不访问外部网络。

**在线预览：<https://ityer-frontend.github.io/insitu-gear-metrology/>**

## 启动

不要直接双击 `index.html`（ES Module 与 import map 在 `file://` 下会被浏览器拦截）。在仓库目录启动任意静态服务器：

```powershell
cd insitu-gear-metrology
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/index.html`。也可以用 Node 的静态服务器，入口文件相同。需要现代浏览器与 WebGL2。

## 交互

- **空格**：启动 / 暂停测量；**R**：复位视角；**C**：剖切 / 外观；**E**：分层爆炸；**M**：静音切换；**D**：调试读数；**1–5**：五个相机预设；**Esc**：关闭帮助、选择或爆炸。
- 拖拽旋转、滚轮缩放、点击部件查看档案；点击机身橙色急停按钮触发急停，复位按钮解除。
- 右侧控制台可切换“自动 / 手动 / 真实 1×”观察倍率、3D 位移视觉放大、X 粗调、M6 微分筒、预紧力、误差源预设和画质。
- “曲线”按钮跳到右侧齿形误差图；移动端则滚动页面到图。
- 电影演示约 27 秒；任意指针、滚轮或键盘操作会立即中断演示，但不会回滚已经发生的测量状态。

## 文件

- `index.html`：已构建的单页，CSS 与业务 JS 内联；本地 Three.js 模块位于 `vendor/three/`。
- `src/`：可维护源码。`build.mjs` 会将 CSS/JS 注入模板，生成根目录 `index.html`。
- 重新构建：
  ```powershell
  npx esbuild src/main.js --bundle --format=esm --external:three --external:'three/addons/*' --outfile=src/app.bundle.js
  node build.mjs
  ```

## 教学口径与简化（页面“数据来源与教学口径”中也可见）

- 源数据同时给出齿圈外径 **D = 4200 mm** 与由 `Z=98 / mn=8 / β=28.3575°` 推得的 `d≈890.9 mm`，二者不能由同一圆柱齿轮公式同时成立。展陈按任务书要求采用 Φ4200 mm 的视觉尺度；双球跨距 **W=258.88 mm、k=11**、齿形评价与误差链按说明书测量口径呈现，局部齿槽配合为教学折中。
- 齿形误差曲线是形态受控的教学示意，并非现场实测；扫描速度 0.5–5 mm/s 为教学设定；3D 位移 ×100–×2000 只夸大测球/杠杆/LVDT 的运动，曲线、读数、电机转速不随视觉放大改变。
- 双球定位卡片中的 `u = 4.5 μm` 是误差预算中的定位重复性分量，不是现场重复性实测；进度条反映演示定位过程。
- 3D 中的微小位移采用高通分量并限幅，以保证机构在 ±5° 挡块内可读。
- 实际验证范围：几何、相机、UI、状态机、交互、响应式、拾取、急停、音效开关与电影序列均在本地浏览器回归；未进行真实测量或计量标定。

## 主要实现

- 双球基准、Y 轴滚珠丝杆传动、红宝石测球、3:1 杠杆、单片簧、LVDT、±22.45° 回转与定位销。
- `IDLE → POSITIONING → APPROACH → SCANNING → RETRACT → REVERSING → APPROACH → SCANNING → DONE` 状态机；0–35 mm 双齿面扫描与 60 点教学采样。
- 双曲线 Canvas 误差图、45 μm 公差带、合格/超差/随机预设、时间轴拖动。
- 五组相机预设、A—A 剖切、装配顺序爆炸图、工程标注、部件拾取、电影演示。
- 画质 `auto / high / smooth`；自动模式在窄屏采用 1.15 DPR、512 阴影与无后处理，桌面按核数选择 DPR；`smooth` 可进一步降级。
- 声音默认静音；首次点击音量按钮才创建 AudioContext，扫描采样、换向锁止、定位、完成提示均与真实状态同步。
- WebGL 上下文丢失、资源加载超时会进入明确的故障页，不会停留在黑屏。
